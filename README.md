# Industry EBIT Analytics

Учебный проект получает бухгалтерскую отчётность из ГИР БО ФНС, рассчитывает
EBIT и строит графики или интерактивную карту через GeoPandas.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск

Для всей работы нужен только один файл:

```powershell
python main.py
```

Программа предложит два режима:

1. **Аналитический.** Пользователь вводит код ОКВЭД, а затем число компаний или
   слово `все`. Во втором случае проект анализирует все подходящие компании по
   этому ОКВЭД. Через расширенный поиск ГИР БО выбираются юридические лица с
   обычной непустой БФО за любой доступный год, загружается история за
   2021–2025 годы и рассчитывается EBIT.
2. **Учебный.** Используются готовые строительные компании из локальной таблицы.
   Если подготовленных файлов нет, `main.py` сам создаст выборку из реестра и
   запустит существующий конвейер.

После сбора программа спрашивает, что построить:

1. распределение EBIT;
2. изменение EBIT с 2022 по 2025 год;
3. интерактивную карту компаний;
4. все визуализации вместе.

Аналитические результаты сохраняются отдельно по коду деятельности, например:

```text
data/okved_62_01_ebit.parquet
data/okved_62_01_ebit_errors.csv
data/okved_62_01_ebit_distribution.png
data/okved_62_01_ebit_growth.png
data/okved_62_01_companies_2025.html
```

## Геообработка

GeoPandas создаёт `GeoDataFrame` на время построения карты.
Отдельный parquet с геометрией не сохраняется. Основная привязка выполняется по
почтовому индексу, а одинаковые запросы к Nominatim кэшируются в системной папке
пользователя, вне проекта.

Упрощённая БФО (`0710096`) не используется: в ней нет отдельных строк процентов,
необходимых для единообразного расчёта точного EBIT.
